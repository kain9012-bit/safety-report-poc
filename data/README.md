# data/

## play-reviews-2026-09.tsv
구글플레이 '안전신문고' 앱 리뷰 **최신 200건** (2026-07-02 ~ 2026-09-17, 2026-09-18 수집).

- 수집 방법: 스토어 리뷰 화면을 브라우저로 열어 '최신순'으로 정렬하고, 화면에 표시된 리뷰를
  그대로 읽어 옮겼다. 비공개 API나 우회 수집을 쓰지 않았다.
- **작성자 이름은 저장하지 않는다.** 개인정보이고 분석에 필요 없다.
- 열: idx, date, rating, useful(도움돼요 수), body
- 욕설만 있는 리뷰 2건은 본문을 `(욕설 리뷰)`로 대체했다.

## classify.py
리뷰를 주제별로 분류한다. 규칙 기반이라 다시 돌려도 같은 숫자가 나온다.

```
python3 classify.py play-reviews-2026-09.tsv > review-analysis.md
```

한 리뷰가 여러 주제에 걸칠 수 있고, 키워드가 하나도 안 걸리면 억지로 끼워 맞추지 않고 남긴다.

## review-analysis.md
위 스크립트의 출력. 별점 분포와 주제별 건수, 각 주제의 실제 문장.

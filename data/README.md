# data/

## play-reviews-2026.tsv
구글플레이 '안전신문고' 앱 리뷰 중 **2026년에 작성된 655건** (2026-01-01 ~ 2026-09-17, 2026-09-18 수집).

- 수집 방법: 스토어 리뷰 화면을 브라우저로 열어 '최신순'으로 정렬하고, 화면에 표시된 리뷰를
  그대로 읽어 옮겼다. 비공개 API나 우회 수집을 쓰지 않았다.
- **작성자 이름은 저장하지 않는다.** 개인정보이고 분석에 필요 없다.
- 열: idx, date, rating, useful(도움돼요 수), body
- 욕설만 있는 리뷰 몇 건은 본문을 `(욕설 리뷰)`로 대체했다.

## classify.py
리뷰를 **성격(설계/고장/행정처리)과 주제**로 분류한다. 규칙 기반이라 다시 돌려도 같은 숫자가 나온다.

```
python3 classify.py play-reviews-2026.tsv > review-analysis-2026.md
```

한 리뷰가 여러 주제에 걸칠 수 있고, 키워드가 하나도 안 걸리면 억지로 끼워 맞추지 않고 남긴다.

- **설계** — 고장이 다 고쳐져도 남는 것. 제안 대상.
- **고장** — 고치면 사라지는 것. 유지보수 과제라 제안에서 뺀다.
- **행정처리** — 접수 이후, 앱 화면 밖의 문제.

## 안전신문고_구글플레이_리뷰분석_2026.xlsx
팀에 돌려 볼 때 이걸 쓴다. 다섯 시트.

- **리뷰 655건** — 원자료 + 성격·주제 분류. 머리글에 필터가 걸려 있어 '설계'만 골라 볼 수 있다.
- **주제 집계** — 주제별·성격별 건수(수식). 원자료를 고치면 숫자가 따라 바뀐다.
- **월별 추이** — 월별 설계/고장/갤러리 차단 건수와 꺾은선 그래프.
- **별점 분포**
- **수집·분류 방법** — 출처, 방법, 한계.

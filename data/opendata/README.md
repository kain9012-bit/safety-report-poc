# 지자체 불법주정차 신고 원자료(공공데이터포털)

담당 공무원 업무를 숫자로 보이기 위해 모은 자료. 수집일 2026-10-11.
전국 월별 현황(`../safetyreport-monthly-2025-2026.tsv`)에는 없는 **건별 처리 결과·불수용 사유·처리 일자**가 들어 있음.

## 들어 있는 것

| 파일 | 내용 | 깃 |
| --- | --- | --- |
| `raw/*.csv` | 원자료 101개(지자체 96곳+). 파일 이름은 `데이터셋ID_지자체.csv` | **안 올림**(120MB, 지번 주소 포함) |
| `sources.csv` | 데이터셋 제목·등록일·수정일·주소 | 올림 |
| `catalog.csv` | 파일별 행 수·기간·칸 이름·불수용 판단 칸·사유 칸 | 올림 |
| `nonaccept-by-city.csv` | 불수용률을 셀 수 있는 27곳의 집계 | 올림 |

- 원자료는 팀 공유 드라이브로 나눔. 다시 받으려면 `sources.csv`의 주소에서 내려받아 `raw/`에 같은 이름으로 넣음.
- `ID미확인_*` 5개는 내려받은 파일 이름만 있고 데이터셋 ID를 확인하지 못함(남해·금산·광산·인천 동구·옥천).
- 인코딩이 섞여 있음(UTF-8, CP949). 스크립트가 알아서 읽음.

## 실행

```
python scripts/opendata-summary.py                      # catalog.csv, nonaccept-by-city.csv 다시 만들기
python scripts/nonaccept-reasons.py                      # 양주·남해 불수용 사유 묶음(앱이 막는 몫)
```

## 주요 결과

- **불수용 사유:** 사유 칸이 있는 곳은 양주시(11,003건)와 남해군(461건)뿐. 사진 규칙으로 제출 전에 막을 수 있는 사유가 양주 43.3%, 남해 35.7%(사유 적힌 28건 기준). 자세히는 `docs/officer-impact.md` 2-2장, 발표자료 '불수용 사유' 장.
- **지자체별 불수용률:** 27곳 중 '부과 건 위주 목록'(대전 서구·아산) 2곳을 뺀 25곳 합계 **18.0%**(59,770/332,167). 전국 월별 현황 20.7%와 비슷한 수준.
- **처리 기간:** 고양시 수용·불수용 모두 중앙값 11일, 포항시 2.6·2.7일. 불수용도 수용과 같은 기간이 걸림.

## 주의

- 지자체마다 칸 이름·값이 다름. 불수용 판단 기준은 `scripts/opendata-summary.py`의 `RULES`에 하나씩 적음.
- '계도'는 불수용이 아닌 별도 조치라 세지 않음.
- CCTV 단속이 섞인 자료(용인·양산·군포·영암)는 안전신문고 건만 셈.
- 불수용률 3% 미만은 미부과 건이 빠진 '부과 목록'일 가능성이 있어 `주의` 표시.
- 장수군은 국민신문고 신고분.

# data/samples — 판독 채점용 사진과 정답표

AI+규칙이 위반 유형과 번호판을 얼마나 맞히는지 재는 자료. **사진 1장 기준**으로 채점한다.

## 지켜야 할 것

- **본인·팀원 차량만** 찍는다. 남의 차 번호판은 개인정보다.
- 사진과 `answers.csv`(번호판 전체가 들어감)는 **깃에 올리지 않는다**(`.gitignore`). 팀 공유 드라이브로 나눈다.
- 깃에 올라가는 것은 이 설명과 빈 양식(`answers-template.csv`)뿐이다.

## 순서

1. 앱 카메라로 찍는다(촬영시각·좌표가 박힌 사진이 실제 신고 사진과 같다). 목표 100장 남짓.
   - 6대 유형 각 13~15장, 위반 아님 10장, 어려운 사진 10장(야간·비·유형 둘 이상)
2. `answers-template.csv` 를 복사해 `answers.csv` 로 저장하고 한 줄에 사진 한 장씩 적는다(한셀·엑셀).
   - **정답은 '사진만 보고 신고할 수 있는 유형'** 이다. 사진에 근거가 안 보이면 그 유형이 아니다.
   - 두 사람이 따로 적고, 다르면 셋이 합의한다. 끝까지 애매하면 `애매`에 O (채점에서 빼고 따로 센다).
   - `구분`: 70장은 `개선`, 30장은 `시험`. **시험용은 발표 직전에 한 번만 돌린다.**
3. 배포 사이트의 `/eval.html`(판독 채점)을 연다 → 정답표와 사진 폴더를 고른다 → 채점 시작.
4. 틀린 사진마다 원인(사진 문제 / AI 판독 / 규칙 / 정답 애매)을 고르고 결과 CSV를 내려받아 공유한다.
5. 고친 뒤 같은 '개선용'으로 다시 돌려 '지난 실행' 표에서 전후를 비교한다.

## 칸

| 칸 | 적는 법 |
|---|---|
| 번호 | 1부터 |
| 파일명 | 사진 파일 이름 그대로(대소문자 무시) |
| 구분 | 개선 / 시험 |
| 정답유형 | 횡단보도 · 인도 · 소화전 · 버스정류소 · 교차로 모퉁이 · 어린이보호구역 · 위반아님 |
| 함께보이는유형 | 사진에 같이 보이는 다른 유형. 여럿이면 `/` 로 |
| 번호판 | 예: 12가3456 (뒤 4자리만 적으면 끝자리로 비교) |
| 번호판보임 | O / X — 사진에서 사람 눈으로 읽히는가 |
| 시간대 | 주간 / 야간 |
| 날씨 | 맑음 / 흐림 / 비 … |
| 애매 | O면 채점에서 뺀다 |
| 메모 | 자유 |

## 지표

- **유형 정답률** — 앱이 자동으로 채우는 유형이 정답과 같은 비율. 비우면(보류) 정답이 아니다. 목표 95%.
- **추천 기준 정답률** — 유형이 여럿 보일 때 '추천' 맨 위가 정답인 비율.
- **번호판 오채움** — 틀린 번호를 채운 건수. 다른 사람에게 과태료가 간다. 목표 0건.
- 100장 중 95장을 맞혀도 실제 실력은 약 89~98% 범위다. 화면에 함께 나오는 '실제 범위'를 같이 말한다.

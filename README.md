# 주정차 신고 자동작성 (safety-report-poc)

안전신문고 **불법주정차 신고 화면**을 어떻게 고치면 좋을지 보여주기 위한 **비공식 시제품**입니다.
국민제안으로 제출할 개선안의 근거 자료이며, 실제 신고는 접수되지 않습니다.

> 이 저장소의 화면은 안전신문고 앱이 아닙니다. 기관 로고·명칭을 쓰지 않으며,
> 모든 화면 상단에 시제품임을 밝히는 띠를 답니다.

## 무엇을 주장하는가

신고서가 요구하는 칸은 여섯 개입니다 — 위반유형, 발생주소, 발생일시, 차량번호, 신고내용, 사진.
그런데 **사진을 찍는 순간 이 중 다섯 개는 이미 정해져 있습니다.** 지금은 국민이 그것을 손으로 다시 적고,
잘못 적어 반려됩니다.

| 신고서 칸 | 어디서 나오나 | 확실도 |
| --- | --- | --- |
| 발생일시 | 촬영 시각 | 확정 |
| 발생주소 | GPS 좌표 → 역지오코딩 | 확정(좌표 오차 범위) |
| 위반유형 | 좌표 × 공공데이터 근접계산 **+** 사진 판독 | 추정 → 교차검증 |
| 차량번호 | 사진 번호판 판독 | 추정 → 사람이 확인 |
| 신고내용 | 위 값으로 문장 생성 | 자동 |

### 설계의 중심: 두 축 교차검증

위반유형을 사진 판독 하나로 정하면 틀렸을 때 변명이 안 됩니다. 그래서 **좌표로 한 번, 사진으로 한 번**
계산하고 두 결과가 **일치할 때만 자동 확정**합니다. 어긋나면 "소화전 4m로 보이는데 사진에는 횡단보도가
보입니다" 하고 신고인에게 고르게 합니다.

자동으로 채운 칸에는 근거 배지(📍좌표 / 📷사진 / ⏱촬영시각)를 답니다. 무엇이 어디서 왔는지 보이지 않으면
신고인이 제출 단추를 누를 수 없습니다.

## 화면 흐름

1. **시작** — 무엇이 자동으로 되는지 알린다
2. **촬영** — 첫 컷 촬영 → 60초 카운트다운 → 첫 컷을 반투명으로 겹쳐 같은 구도 유도 → 둘째 컷
3. **자동작성 검토** — 칸마다 값 + 근거 배지, 고칠 곳만 고친다
4. **제출 전 점검** — 반려 사유 5가지를 신호등으로 점검한다

## 개발

```bash
npm install
npm run dev        # http://localhost:3000
npm run lint       # 타입 검사
npm run build
```

- Node 22 (`.nvmrc`)
- Vite 6 + React 19 + TypeScript + Tailwind CSS v4
- 카메라·위치는 **https 또는 localhost 에서만** 열립니다. 폰으로 볼 때는 배포본을 여세요.

### 환경변수

`.env.example` 를 `.env.local` 로 복사해 채웁니다. **키는 서버리스 함수(`api/`)에서만 읽습니다.**
`VITE_` 접두사를 붙이면 브라우저 번들에 그대로 박히니 붙이지 마세요.

| 이름 | 쓰임 |
| --- | --- |
| `DATA_GO_KR_KEY` | 공공데이터포털 표준데이터(소화전·횡단보도·버스정류장·어린이보호구역) |
| `VWORLD_KEY` / `KAKAO_REST_KEY` | 좌표 → 도로명주소 |
| `VISION_PROVIDER`, `VISION_API_KEY` | 사진 판독(번호판·장면) |
| `VITE_DEMO_MODE` | 1이면 키 없이 고정 시나리오로 흐름만 시연(화면에 '시연 모드' 띠 표시) |

### 배포

Vercel. 정적 화면과 `api/` 서버리스 함수를 한 번에 올립니다. data.go.kr 은 브라우저에서 직접 부르면
CORS 에 막히고, 비전 AI 키는 프론트에 둘 수 없어 **함수 중계가 필수**입니다.

## 자료 출처

- 소방용수시설(소화전)·버스정류장 표준데이터 — 활용신청 시 정확한 데이터셋 번호를 확인해 이 목록에 적는다
- [전국횡단보도표준데이터](https://www.data.go.kr/data/15028201/standard.do)
- [전국어린이보호구역표준데이터](https://www.data.go.kr/data/15012891/standard.do)
- 신고 요건(1분 간격·동일 구도 2장·익일까지 접수)은 안전신문고 안내를 따릅니다.

## 지켜야 할 선

- 실제 기관 화면을 흉내 내지 않습니다. 로고·기관명·접수번호를 만들지 않습니다.
- **없는 값을 그럴듯하게 채우지 않습니다.** 키가 없으면 비워 두고 왜 비었는지 적습니다.
- 자동 판정에는 한계를 함께 적습니다. GPS 오차는 5~10m 이고, 기준 거리는 5m 입니다.
- 시민 사진을 외부 AI로 보내는 구조는 PoC 한정입니다. 제안서에는 자체 모델·온프레미스 처리를 명시합니다.

# 안전신문고 실제 앱 확인 기록

- 확인일: 2026-09-28, 화면 시계 약 12:57–13:01
- 방법: 1차는 iPhone 미러링 직접 조작, 2차는 USB + QuickTime 화면 관찰과 사용자의 휴대전화 직접 촬영
- 설치 앱 버전: 설정 하단 ‘버전정보 2.5.3’ 확인. 최신 배포 버전인지는 별도 확인하지 않음.
- 범위: 불법주정차 6대 유형 + 기타 팝업, 지역별 안내 목록, 사진 도움말, 횡단보도 유형의 미디어 선택 및 카메라 진입, 설정 화면
- 촬영·제출: 1차 미러링에서는 카메라 사용 제한. 2차 USB 화면 연결에서 사용자가 실내 사진 2장을 촬영·첨부함. 신고 제출은 하지 않음.
- 관찰과 해석을 구분한 메모. 화면의 개인 위치·계정 정보는 기록에서 제외.

## 1. 유형 선택과 촬영 순서

불법주정차 탭 → 유형선택 → 유형별 안내 팝업 → 확인 → 선택 유형 및 기본 신고내용 표시 → 촬영/앨범 → 미디어 선택 → 사진촬영.

유형이 선택되지 않은 상태에서 ‘촬영/앨범’을 누르면 먼저 유형을 선택하라는 알림으로 진입을 막는다. 따라서 사진 우선 제안은 실제 진입 조건 변경을 필요로 한다.

유형 선택 창에는 도로교통법 묶음의 소화전, 교차로 모퉁이, 버스 정류소, 횡단보도, 어린이 보호구역, 인도, 기타가 있다. 아래에는 장애인 전용구역, 소방차 전용구역, 친환경차 충전구역이 다른 법령 묶음으로 표시된다. 전용구역의 세부 팝업은 이번 확인 범위에서 제외했다.

여러 팝업에 이륜차는 자동차·교통위반 메뉴의 이륜차 위반 유형으로 신고하라는 안내가 있다. 소화전·어린이보호구역·인도·기타 팝업을 스크롤해 하단 안내까지 확인했다. 교차로·버스정류소·횡단보도는 상단 핵심 정의와 구성 확인이며 모든 하단 문구의 동일성을 검증하지는 않았다.

## 3. 지역 차이에 대해 앱에서 확인된 것

어린이보호구역·인도·기타 팝업은 지방정부별로 운영기준 등이 다를 수 있어 신고지역의 행정예고를 확인하도록 안내한다.

기타 팝업의 ‘지방정부별 운영기준 안내’를 누르면 ‘행정예고 안내’ 화면이 열린다. 지역 선택·검색과 지방정부명별 ‘게시판 바로가기’ 목록이 있다. 이번에 확인한 경로는 지역별 게시판을 찾아가는 구조이며, 위치에 따른 모든 규칙의 자동 적용 여부까지 확인한 것은 아니다. 특정 지자체 게시판으로는 이동하지 않았다.

## 4. 사진 관련 도움말과 미디어 선택

사진 옆 물음표 도움말은 저장 시 용량 조정과 제출 전 번호판·대상 식별 확인을 설명한다.

횡단보도 선택 후 ‘촬영/앨범’ 메뉴에는 ‘사진촬영’과 ‘안전신고 갤러리’가 표시된다. 하단 그림과 설명은 같은 위치·각도와 같은 차량 방향에서 간격을 두고 사진을 찍고, 주변 배경과 번호판을 포함하도록 안내한다. 이 화면에서는 1분 간격이 표시된다. 갤러리 내부는 열지 않았다.

실제 카메라 UI에는 셔터, 배율, 플래시, 카메라 전환 등이 보였으나 미러링 제약으로 실영상과 촬영 완료 후 동작을 확인할 수 없었다. 촬영 후 인식·보완·타이머·유효성 검사 여부에 대해서는 결론 내리지 않는다.

## 5. 기존 인식 기능

설정 화면에 ‘번호판 자동인식 설정’ 항목이 있으며 확인 시 미사용 상태였다. 설정을 변경하지 않았다. 이 기능의 적용 신고유형, 정확도, 촬영 중/후 처리 방식은 확인하지 못했다. 따라서 새 설계에서는 번호판 인식을 신규 기능으로 단정하지 않고 기존 기능의 활용 범위를 먼저 조사해야 한다.

## 6. 사전설계 반영 사항

1. 유형을 미리 고르도록 막는 진입 조건을 바꾸고, 첫 사진을 유형 미정 상태로 안전하게 저장하는 흐름을 설계한다.
2. 공통 촬영 안내는 촬영 전에 짧게 제공하고, 유형별 기준은 촬영 후 검출 근거에 맞춰 제시한다.
3. 횡단보도 분석 범위에 정지선과 연결 구역을 포함한다.
4. 이륜차 등 다른 신고 메뉴로 가야 할 대상을 미분류와 구분한다.
5. 기존 번호판 자동인식과의 연계 범위를 확인한다.
6. 지역별 행정예고 목록과 실제 적용 규칙 데이터를 연결하는 방안을 설계하되, 현재 앱이 이를 자동 적용하지 않는다고 단정하지 않는다.
7. iPhone 직접 촬영을 통한 후속 검증 항목: 첫 사진 저장, 두 번째 사진 간격, 유형 변경 시 사진 보존, 기존 자동인식, 촬영 후 오류·재촬영 안내. Android는 별도 확인 필요.


## 7. USB 화면 연결 후 실제 촬영 시험

- 시험 조건: iOS 앱 2.5.3, 횡단보도 유형 선택, 차량·번호판·횡단보도가 없는 실내 장면, 사진 2장으로 구성된 1회 시험.
- 방법: USB 재연결 후 QuickTime 입력 메뉴의 ‘화면’ 항목에서 iPhone을 선택. 휴대전화 직접 조작을 관찰·녹화했다. 카메라 입력과 화면 입력은 별개였다.
- 기록 영상: `안전신문고_iOS253_실내촬영시험_20260928.mov` (약 3분 24초). 영상에는 시험 화면의 위치 정보 등이 포함되므로 대외 보고서에 원본을 그대로 삽입하지 않는다.
- 첫 사진: 실내 사진을 촬영·사용한 후 첫 칸에 첨부됨. 차량·번호판·횡단보도가 없다는 이유의 재촬영 안내는 관찰되지 않음.
- 시간: 첫 첨부 후 ‘남은 시간 60초’, 이후 35초·14초 표시를 직접 관찰. 대기 후 실제 카메라 화면에 진입하는 모습과 두 번째 사진 첨부를 확인.
- 두 번째 사진: 두 실내 사진의 썸네일이 모두 표시됐고, ‘촬영/앨범’ 버튼이 다시 보임.
- 제한: 카운트다운 중 버튼을 눌러도 촬영 화면이 열리지 않았다는 사용자 확인을 받음(직접 관찰한 카운트다운과 사용자 조작 결과를 구분해 기록). 촬영 시각 검증·갤러리 우회 검사·제출 단계 검사는 별개로 미검증.
- 자동인식: 앞선 설정 화면에서 번호판 자동인식은 미사용이었다. 이번 실내 시험은 번호판 OCR 정확도나 활성화 상태에서의 성능을 평가한 것이 아님.
- 해석: 이 1회 시험에서는 사진 첨부 단계에서 내용 부족을 이유로 차단하거나 재촬영을 요구하는 동작을 관찰하지 못했다. 모든 조건에서 그러한 기능이 없다는 결론은 내리지 않는다.
- 개선안 반영: 시간 안내는 이미 존재하므로 신규 기능 성과로 제안하지 않는다. 기존 타이머를 유지·연계하고, 사진의 유형 적합성·필수 증거 부족 안내를 주요 개선 가설로 설정한다.


## 8. 번호판 자동인식 설정 변경 후 추가 사진 시험

- 사용자는 번호판 자동인식 설정을 켰다고 확인했다. 변경된 ‘사용’ 스위치 화면은 직접 관찰하지 못했으므로 활성화는 사용자 진술 근거로 기록한다.
- 세 번째 가상 번호판 사진은 설정 변경 전 촬영이었다고 사용자가 정정했다. 따라서 활성화 후 시험 표본에서 제외한다.
- 네 번째 사진은 설정 변경 후 사용자가 촬영했다고 확인했다. 원래 제안한 ‘새 신고의 첫 사진’ 시험은 수행되지 않았으며, 기존 횡단보도 신고의 네 번째 추가 사진으로만 관찰했다.
- 자극: 실제 차량·실물 번호판이 아닌 모니터의 가상 번호판 카드. 촬영 거리·번호판 크기·화질·모아레는 통제하지 않았다.
- 직접 관찰: 사진 4장이 첨부된 신고 화면. 이 시점에는 인식된 차량번호나 인식 실패·재촬영 안내가 별도로 표시되지 않았다.
- 사용자는 네 번째 사진 촬영·사용 직후 아무 안내도 나오지 않았다고 확인했다. 별도 번호 인식 결과·인식 실패·재촬영 안내 없이 사진이 첨부됐다는 사용자 확인이며, 첨부 후 화면의 직접 관찰과 구분해 기록한다.
- 기록: `안전신문고_iOS253_자동인식설정후_추가사진시험_20260928.mov`. 녹화는 중지·저장했다. 녹화 시작 전 동작이나 관찰하지 않은 일시적 안내까지 모두 포착했다고 주장하지 않는다.
- 판정: 기존 번호판 인식 기능의 성공·실패 또는 적용 범위를 확정할 수 없는 제한적 시험. 첫 번째 필수 사진·다른 신고 메뉴·실물 번호판·제출 시점 결과로 일반화하지 않는다.
- 개선안: 번호판 문자열 인식과 ‘신고 유형/증거 충족도 판단’을 별개 기능으로 정의한다. 이번 시험으로 기존 OCR 기능이 없거나 불량하다고 주장하지 않는다.

## 9. 유형별 기준 전수 점검 — 추가 직접 관찰(2026-09-28)

사용자 지적으로 시안 확정을 보류하고 유형별 안내부터 점검. 미러링 재인증 후 사진이 없는 신고 화면에서 진행. 제출하지 않음. 아래는 iOS 2.5.3 화면 문구 관찰이며 전국 법적 수리 기준이나 실제 검사 구현을 보증하지 않음.

### 장애인 전용구역
- 안내문 상단부터 하단까지 읽음. 불법주차와 물건 적치·통행로 가로막기 등 주차방해를 구분.
- 같은 위치·방향의 전면 2장 또는 후면 2장, 앱 촬영 시차 1분 이상, 사진 2장 이상.
- 모든 사진에 위반장소·위반사항(전면 주차표지 유무, 보행상 장애인 탑승 여부 등)·차량번호 식별을 안내. 사진만으로 탑승 여부를 확정할 수 있다고 해석하지 않는다.
- 위반 당일 촬영 후 2일 이내 신고 유효라는 문구. 지방정부별 운영 차이 경고.
- 촬영/앨범에는 공통 그림(1분 이상·동일 위치/각도·주변배경·번호판), 사진 각 30MB/총 180MB. 실제 카메라/타이머는 미시험.

### 소방차 전용구역
- 안내문 전체 확인. 공동주택 전용구역 주차·진입로 물건 적치 등, 상시 신고 가능 안내.
- 동일 위치·방향, 전면 2장 또는 후면 2장, 시차 5분 이상, 사진 2장 이상 최대 4장.
- 모든 사진에 전용구역 노면표시·위치(동수 표시/특징적 구조물)·차량번호 식별.
- 당일 촬영한 사진으로만 당일 신고 안내.
- 미디어 메뉴 공통 그림에는 1분이 남아 있고 별도 붉은 문구로 소방차는 5분 이상 사진 2장 이상 명시. 문구 충돌 가능성을 검토하되 실제 타이머가 1분이라고 주장하지 않음.

### 친환경차 충전구역
- 안내문 상단부터 최하단까지 확인. ‘충전방해행위 안내’ 및 ‘과태료 부과 예외 안내’ 별도 링크의 내용은 아직 미열람.
- 충전구역 비전기차/비PHEV 주차, 친환경차 전용주차구역 비전기차/비하이브리드/비수소차 주차, 충전방해행위로 대상 구분.
- 기본: 앱 직접 촬영 사진·동영상만. 동일 위치·방향 전면 2장 또는 후면 2장, 1분 이상 사진 2장 필수(최대4장). 장소(전용주차/충전구역 표시 포함), 위반사항, 번호판 식별.
- 급속충전: 전기차/PHEV 계속 주차 1시간 초과, 최초와 1시간 경과 후 사진2장.
- 완속 PHEV: 7시간 초과, 최초·7시간 경과 후 사진 + 중간3~5시간 사진 또는 충전기 화면 등으로 7시간 초과 계속 주차를 확인할 동영상. 총 주차시간 산정에서 오전0~6시 제외하며 중간·마지막 촬영시점 산정에서도 제외 문구.
- 완속 전기차:14시간 초과, 최초·14시간 경과 후 사진 + 중간5~9시간 사진 또는 계속 주차를 증명하는 충전기 화면 등 동영상.
- 충전구역 앞 주차 방해:1분 이상 사진2장 + 주차브레이크 체결 사실 확인 가능한 동영상.
- 사진·동영상 촬영시점 기준 다음날까지 신고. 아파트 허용 표시 구역 등에 과태료 예외 가능 안내. 지방정부별 운영 및 행정예고 링크.
- 미디어 메뉴: 사진2장 먼저 첨부 후 동영상 촬영·첨부 가능 문구를 확인. 처음에는 사진촬영/안전신고갤러리 버튼만 표시. 실제 영상 메뉴 활성화 및 장시간 검사 미시험.

### 6대 유형 및 기타 — 안내/촬영 메뉴 대조
- 소화전: 주변5m 정지차량; 주정차 금지 표지판·황색 실선/복선 설명. 도식+사진. 미디어에서 공통1분/2장/동일각도/주변배경/번호판 안내를 직접 확인.
- 교차로 모퉁이: 가장자리·모퉁이5m 정지차량; 도식+사진; 하단까지 읽음. 미디어 공통1분/2장 안내 확인.
- 버스정류소: 정류소 기준10m 정지차량; 도식+사진; 하단까지 읽음. 미디어 공통1분/2장 안내 확인.
- 횡단보도: 정지선부터 횡단보도까지 면적 침범; 도식+사진; 하단까지 읽음. 미디어 공통1분/2장 안내 확인.
- 어린이 보호구역: 초등학교 주출입문 앞 도로, 평일08~20시; 주정차금지 안전표지(표지판 또는 황색실선/복선) 및 보호구역 표시가 사진으로 확인돼야 함. 도식2개. 지방정부 운영기준 링크 및 지역차이 경고. 미디어 공통1분/2장.
- 인도: 보도와 차도 구분된 도로의 보도; 그림 없이 텍스트(상단까지 스크롤 확인). 이륜차는 별도 자동차·교통 메뉴. 지방정부별 운영시간·면제 차이. 하단 앱직접촬영/안전신고갤러리만 인정, 일반카메라/일반갤러리 불가 안내. 미디어 공통1분/2장.
- 기타: 도로교통법32·33조상 다른 주정차금지구역; 지방정부별 신고구역·시간 등 차이. 동일위치방향 전면2장/후면2장, 앱사진2장+, 모든사진 위반지역·번호판 식별. 유형 안내문에는 고정 간격 미표시. 미디어는 공통그림 대신 '촬영 시간 간격 지방정부별 차이(더보기)'를 안내하고 동일위치2장이상/다음날자정까지 촬영한 사진의 앱갤러리 첨부를 설명.
- 교차로·버스·횡단보도·어린이·인도·기타 안내 하단의 앱직접촬영/안전신고갤러리 출처 제한을 직접 읽었다. 소화전 최하단 전체 문구 재확인은 생략하여 다른 유형과 동일하다고 단정하지 않는다.
- 총10개 유형의 기본 안내 및 미디어 메뉴를 직접 대조했다. 안내 내용 확인과 실제 카메라 타이머 구현 확인은 별개이며 후자는 기존 횡단보도 시험만 있다.
- 친환경차 '과태료 부과 예외 안내'는2쪽 문서가 열림을 확인했으나 작은 글씨를 전부 판독하지 못함. '충전방해행위 안내' 별도문서와 지자체 전체 행정예고는 미완료. 전국의 모든 법적 예외를 조사 완료했다고 주장하지 않는다.

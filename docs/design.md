# 설계 메모

작업하면서 내린 결정과 그 이유를 적는다. 코드를 고치기 전에 여기부터 읽는다.

## 왜 안전신문고인가

주정차 위반 신고의 실제 창구는 안전신문고다. 국민신문고는 민원·제안 창구이므로,
개선 대상은 안전신문고로 쓰고 제안 자체는 국민제안으로 낸다.

## 위반유형 판정

6대 유형: 소화전 5m · 교차로 모퉁이 5m · 버스정류소 10m · 횡단보도 · 어린이보호구역 · 인도.
지자체별로 대상 유형이 다를 수 있어(인도 포함 여부 등) **판정이 아니라 추천**으로 낸다.

- **좌표 축** — 표준데이터의 시설 좌표까지 거리를 재고, 기준 거리와 비교한다.
  GPS 정확도(`accuracy`)를 함께 보여준다. 정확도가 기준 거리보다 나쁘면 자동 확정하지 않는다.
- **사진 축** — 장면 판독으로 소화전·횡단보도·정류소 표지 등을 찾는다.
- 두 축이 **일치**하면 자동 확정, **어긋나면** 사람에게 묻는다. 한 축만 있으면 추천만 한다.

## 반려 사전점검

자주 나오는 반려 사유를 제출 직전에 신호등으로 본다.

1. 두 컷 간격이 60초 미만
2. 촬영일 익일이 지남(남은 시간 표시)
3. 사진에 촬영시각 표시 없음
4. 차량번호 판독 불가
5. 위치 특정 불가(좌표 없음 또는 정확도 불량)

## 하지 않기로 한 것

- 가짜 접수번호 생성 — 접수된 것처럼 보이면 안 된다.
- 표본 데이터로 화면 채우기 — 못 받은 값은 비워 두고 이유를 적는다.
- 구획 단위 스크롤(scroll-snap) — 이전 프로젝트에서 걷어냈다.

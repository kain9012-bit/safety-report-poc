논의 내용 10

  1. 첫 사진 즉시 판독
    • 첫 사진 촬영 즉시 AI 전송 → 두 번째 촬영 전 유형·발생지역·내용 작성
    • 유형에 맞지 않는 사진이면 무엇이 부적합한지 안내 후 첫 사진 재촬영(예: ‘소화전이 나오게 다시 찍어 주세요’)
    • 안내 없이 처음으로 되돌리지 않기
  2. 두 사진 같은 자리 판정
    • 두 사진이 일정 비율(예: 50%) 이상 겹치면 통과, 미달 시 ‘일치하지 않음’ 알림
    • 좌표 비교만으로는 부족 — 같은 좌표라도 방향이 다르면 문제
    • 실제 경험: 상황상 반대편에서 찍기도 함 → 사람이 보면 같은 자리, 번호판 일치 시 통과 필요
    • 접수 현장: 생각보다 느슨한 판단(완전히 다른 사진만 아니면 동일 처리)
    • 두 장 모두 번호판 식별, 같은 번호여야 신고 가능
  3. 유형 판정·복수 유형·기타
    • 첫 사진에 유형 2개 이상 → 사람이 선택, AI 추천·권장(또는 유사도 %) 표시
    • 예: 소화전보다 어린이보호구역 우선 추천
    • ‘기타’ 선택 이유 추정: 유형 고르기 귀찮음, 두 유형이 같이 있어 판단 곤란 → 사진 판정으로 기타 감소 기대
    • 기타 신고 줄글의 핵심 키워드 추출 — 후속 활용 가치, 이번 범위(신고 편의성) 밖
  4. 내용 칸
    • 유형·장소·시각·차량번호가 채워지면 더 쓸 내용 거의 없음
    • 줄글 대신 개조식 — 받는 사람이 공무원
    • 담당 공무원 의견: 가장 큰 바람은 분류 정확도 — 현재 사람이 하나씩 재분류, 촬영 부실 사진 다수
  5. 대기시간·타이머
    • 현재 앱: 남은 시간 안내 없음, 두 번째를 찍어야 간격 적합 여부 표시 → 여러 번 재촬영
    • 1분인지 5분인지 사용자가 모름, 현장에서 안내문 읽을 시간 없음
    • 60초→0초 카운트다운, 0초에 소리·진동 알림
    • 앱 전환·최소화 때도 화면 맨 위에 남은 시간 표시(아이폰 다이내믹 아일랜드 형식)
    • 1~5분 휴대폰 들고 서 있기 눈치 보임 → 대기 중 자리 이동 허용 필요
  6. 이어하기
    • 가장 큰 불만: 한 장 찍고 다른 앱을 쓰다 돌아오면 처음부터 다시
    • 앱 전환·종료 후에도 진행 중 신고부터 재개, 저장소에 ‘이전 신고 이어하기’
  7. 화면 구성
    • 스크롤형 대신 단계별 화면 전환, 한 화면에 한 작업(토스 방식)
    • 안전신문고 UI 틀 유지, 편의성 위주 수정
    • 사진 먼저 — 다른 칸부터 채우고 나중에 찍는 사람 방지
    • 텍스트 과다·가독성 낮음(들여쓰기·띄어쓰기 미흡) 개선
  8. 지자체 규정
    • 지자체·지역마다 규정 차이, 유형별 간격 차이
    • 촬영 전 좌표로 관할 지자체 판별 → 규정·간격 자동 반영
  9. 위치 사용
    • 신고 위치 = 사진 위치(촬영 후 이동해도 무관)
    • 휴대폰 위치 = 촬영 전 주변 버스정류장·소화전 확인용
  10. 형태·범위
    • 앱 구현 여부 미결 — 백그라운드 남은 시간 표시는 앱에서 구현 제안
    • 동영상 촬영안은 범위가 넓어 제외(이전 논의 재확인)

합의된 신고 흐름

첫 사진이 부적합하면 바로 다시 찍고, 두 장이 겹치고 번호판이 같아야 제출

첫 사진 단계에서 부적합 사진을 걸러 재촬영 횟수 축소, 대기 중 앱을 벗어나도 진행 상태 유지.

결정사항 12

  • 화면 구성사진 먼저, 이후 단계별 화면 전환(한 화면 한 작업), 안전신문고 UI 틀 유지
  • 첫 사진 판독촬영 즉시 유형·발생지역·내용 작성, 부적합 시 이유 안내 후 첫 사진 재촬영
  • 복수 유형사람이 선택, AI 추천·권장 표시
  • 대기시간지자체·유형별 간격으로 60초→0초 카운트다운, 0초에 소리·진동 알림
  • 두 번째 촬영첫 사진 잔상 표시
  • 제출 조건두 사진 겹침 일정 비율(예: 50%) 이상 + 두 장 번호판 식별·일치
  • 이어하기앱 전환·종료 후에도 진행 중 신고 재개, 저장소의 ‘이전 신고 이어하기’
  • 지자체 규정촬영 전 좌표로 관할 지자체 판별, 규정·간격 자동 반영
  • 가독성글자 양 축소, 들여쓰기·띄어쓰기 정리
  • 내용 칸(제안)줄글 대신 개조식 자동 작성
  • 앱 구현 시 추가앱 전환·최소화 때 화면 맨 위 남은 시간 표시(아일랜드 형식)
  • 제외동영상 촬영

기존 앱 신고 절차

안전신문고 앱 불법주정차 신고 순서. 단계별 화면, 불편, 시제품 변경점.

단계기존 앱불편시제품

남은 쟁점

  • 앱 vs 웹: 백그라운드 남은 시간 표시·알림은 앱이 유리, 시연은 현재 웹앱

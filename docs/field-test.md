# 현장 확인

배포본을 폰으로 열어 실제로 찍어 보는 단계. **이 확인이 끝나야 자동작성 설계를 확정할 수 있다.**

> **나가기 전에**: `src/lib/rules.ts`의 `INTERVAL_SEC`를 60으로 되돌려 배포했는지 확인한다.
> 시험용 3초로 두면 화면에 '테스트용'이 뜨고, ③·⑦의 숫자가 의미 없어진다.

가장 중요한 건 ③과 ⑦이다. 나머지는 고치면 되는 것이고, 그 둘은 **제안의 전제가 맞는지**를 묻는다.

---

## ① 카메라와 권한

- [ ] 권한 요청이 뜨고, 허용하면 **후면 카메라**로 열리는가 (전면으로 열리면 설정 손봐야 함)
- [ ] 화면이 스크롤 없이 한 번에 들어오는가 — 주소창이 나타났다 사라져도
- [ ] 한 손으로 촬영 단추에 엄지가 닿는가

## ② 위치 정확도 — 숫자를 적어 둘 것

| 장소 | 표시된 정확도 | 메모 |
| --- | --- | --- |
| 넓은 도로변 | ±___m | |
| 건물 사이 좁은 길 | ±___m | |
| 지하주차장 입구 | ±___m | |
| 아파트 단지 안 | ±___m | |

**이 숫자가 자동 판정의 운명을 가른다.** 시험 코드로 확인해 둔 바로는, 기준 10m인
버스정류소를 정확도 8m로 재면 4~16m 구간을 전혀 못 가른다. 현장에서 ±5m 안쪽이 흔하면
추천의 쓸모가 커지고, ±15m가 흔하면 좌표 판정은 참고용으로만 써야 한다.

## ③ 60초 타이머 — 핵심

첫 번째 사진을 찍고 나서 **각각 해 보고 남은 시간이 그대로인지** 확인한다.

- [ ] 홈 화면으로 나갔다가 돌아오기
- [ ] 다른 앱(메신저 등)을 열었다가 돌아오기
- [ ] **화면을 껐다가 켜기**
- [ ] 브라우저 탭을 바꿨다가 돌아오기
- [ ] 브라우저를 완전히 닫았다가 다시 열기 (이어하기가 작동해야 함)
- [ ] 0초가 되면 **소리**가 나는가 (셔터를 누른 뒤라야 소리 권한이 생긴다)
- [ ] 0초가 되면 **진동**이 오는가 (안드로이드 크롬만. 아이폰은 안 되는 것이 정상)
- [ ] 다른 앱을 보고 있을 때 **시스템 알림**이 오는가 (알림 권한을 허용했을 때)

지금 안전신문고 앱은 화면이 비활성화되면 카운트가 멈춘다. **그 차이를 직접 겪어 보는 게
이 확인의 목적이다.** 되면 되는 대로, 안 되면 어디서 끊기는지 적는다.

## ④ 겹쳐보기

- [ ] 첫 번째 사진이 반투명으로 보이는가
- [ ] 그걸 보고 같은 구도를 잡는 게 실제로 쉬운가
- [ ] 투명도 35%가 적당한가 (너무 진하면 실제 화면이 안 보이고, 너무 옅으면 쓸모없음)

## ④-2 같은 자리 판정(겹침) — 기준값 맞추기

겹침 50%·닮음 0.45는 합성 장면으로만 맞춘 값이다. **현장 사진으로 다시 맞춘다.**

- [ ] 같은 자리에서 두 번째 사진 → '같은 자리'로 통과하는가
- [ ] 한두 걸음 옆으로 옮겨 찍기 → 통과하는가(통과해야 맞다)
- [ ] 다섯 걸음 이상 옮기거나 다른 차를 찍기 → 막히는가(막혀야 맞다)
- [ ] 가까이 다가가 찍기(확대) → 막히는가(지금 방식의 한계)

| 상황 | 겹침 | 닮음 | 통과 |
| --- | ---: | ---: | --- |
| 같은 자리 | ___% | ___ | |
| 한두 걸음 | ___% | ___ | |
| 다섯 걸음 | ___% | ___ | |

## ④-3 첫 번째 사진 판독

- [ ] 번호판이 안 보이게 찍으면 이유와 함께 **다시 찍기**가 뜨는가
- [ ] 위반 장소(횡단보도 등)가 안 보이게 찍으면 같은 안내가 뜨는가
- [ ] 유형이 둘 보이는 자리(예: 횡단보도 + 교차로 모퉁이)에서 **추천**이 맞는 쪽에 붙는가
- [ ] 판독에 걸리는 시간 ___초 (남은 시간 대기와 겹쳐서 체감이 어떤가)

## ⑤ 사진 품질 — 주간과 야간 모두

- [ ] 사진 왼쪽 아래에 **촬영시각과 좌표**가 찍혔는가
- [ ] **번호판이 읽히는가** — 주간
- [ ] **번호판이 읽히는가** — 야간 (리뷰에서 가장 많이 나온 불만)
- [ ] 비 오는 날 / 역광에서는 어떤가

## ⑥ 이어하기

- [ ] 첫 번째 사진만 찍고 브라우저를 닫았다가 다시 열면 복구되는가
- [ ] '처음부터' 단추로 지워지는가
- [ ] 사생활 보호 모드에서도 앱이 죽지 않는가 (저장만 안 되면 정상)

## ⑦ 시간 재기 — 제안서에 들어갈 숫자

**스톱워치로 잰다.** 이게 Before/After 표의 After 칸이 된다.

| 구간 | 시간 |
| --- | --- |
| 앱을 열고 첫 번째 사진 찍기까지 | ___초 |
| 60초 대기 (고정) | 60초 |
| 두 번째 사진 찍고 완료까지 | ___초 |
| **합계** | **___초** |

같은 날 **안전신문고 앱으로도 똑같이 재서** 나란히 적는다. 탭 횟수도 센다.
남의 말이 아니라 우리가 잰 숫자여야 한다.

| | 안전신문고 | 개선안 |
| --- | ---: | ---: |
| 탭 횟수 | ___회 | ___회 |
| 소요 시간 | ___초 | ___초 |
| 화면 전환 | ___회 | ___회 |

## ⑧ 사진 표본 모으기

확인하는 김에 `docs/test-data.md` 의 표본도 같이 모은다.
앱이 좌표·시각·정확도를 자동으로 기록하니, 찍고 나서 **유형과 차량번호 뒤 4자리만**
`data/samples/answers.csv` 에 적으면 된다.

- [ ] 주간 / 야간 각각
- [ ] 전북 / 서울 각각

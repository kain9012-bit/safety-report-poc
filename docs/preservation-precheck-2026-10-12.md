## 유지한 기능

카메라·앨범 진입, 첫 사진 판독과 재판독, 대기 알림, 두 사진 겹침, 유형 선택, 지도·주소 수정, 번호판 확대·수정, 본문 자동 작성과 수동 편집, 단계별 화면, 보관함, 소요시간·누른 횟수, 담당자 요약, 한국 시각 처리, 지역 규정 신선도, 주정차금지구역 참고 자료, 발표자료·판독 평가 화면·빌드 표식을 유지했다. GitHub 원본의 테스트용 3초 간격도 그대로이며 공식 촬영 간격을 충족한다는 뜻이 아니다.

## 검증

- 웹 TypeScript 검사와 프로덕션 빌드 성공. 기존 기본 테스트 247개를 포함해 **24개 파일 / 304개 테스트 통과**. 한국 시각과 `TZ=America/Los_Angeles`에서 각각 304개 통과.
- App 통합 12개: 교체 후보 보존·취소·앱 재마운트 복원, 커밋 전 화면 유지, 저장 실패·재시도, 제출 시점 기한, 최신 수동 본문 보존, 읽기·삭제 실패, 늦은 AI·보관함 응답, 앨범 작업 잠금. 카메라/외부 판독과 저장 함수는 모의 구현으로 분리했다.
- IndexedDB 추가 10개: fake-indexeddb에서 실제 요청·트랜잭션 중단/순서/복사/열기 오류/자동 삭제 제거를 검증했다.
- 실제 React 점검 화면 4개: 자정·focus·visibility·규정 신선도 경계. 번호판 안내/촬영 확인 UI 8개.
- 웹 브라우저 실행: `http://127.0.0.1:4180/`에서 시작 화면, 기존 안내 창 열기, 레이아웃과 빌드 표식 확인. 브라우저 실제 카메라·앨범 업로드·전체 신고 동선 E2E는 이번에 수행하지 않았다.
- iPhone: 서명 없는 generic iOS Debug 빌드 성공. iPhone 18 Pro / iOS 27 시뮬레이터 XCTest **20개 통과**(기존 15 + 신규 5). 테스트 앱 실행을 포함하지만 화면 전체 수동 순회·실기기 촬영은 미검증.
- 실제 번호판 인식 정확도·물리적 저장공간 부족·공식 신고 적합성은 검증하지 않았다. 모든 추가 회귀검증은 합성 자료를 사용했고 실제 사진·API 키를 추가하지 않았다.
- 공유 작업공간 `../outputs/preservation_precheck_20261012/`에 결과 JSON, 웹 테스트 로그, iPhone 빌드·테스트 로그, iPhone 변경 패치와 변경 전 소스를 보관했다.

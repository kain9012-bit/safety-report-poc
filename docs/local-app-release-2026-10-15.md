# 로컬 웹·iPhone 앱 작업본 — 2026-10-15

사용자 결정에 따라 **로컬 웹과 Xcode 앱을 준비하고 GitHub 작업 브랜치에 푸시하는 방식**으로 진행한다. Vercel 운영 전환은 보류한다. 이 문서가 앞선 문서의 ‘로컬 변경 미푸시’ 표기 이후의 현재 작업 상태를 설명한다.

## 이번에 함께 기록하는 변경

- 앞서 요청한 화면 단순화: 웹의 기존 5단계를 유지하고 상세 질문을 선택 영역으로 접었다. iPhone은 촬영부터 시작해 확인·기기 보관으로 진행한다. 원본 보존과 세부 분석 기능은 유지한다.
- 앱·서버 응답 호환: 구형 기본 설명과 최신 상세 관찰을 구분한다. 구형 문장만으로 새 상세 관찰을 만들지 않는다. 사진 개수·ID·입력 버전이 다르면 결과를 적용하지 않는다. 구형 서버에는 미지원 확대 요청을 반복하지 않는다.
- 최신 서버의 응답 검증: AI가 필수 `observations` 또는 `detailRequests` 배열을 누락하면 오류로 처리한다. 실제 빈 배열과 누락을 구분한다.
- `GET /api/vision`에서 상세 분석 버전과 지원 기능을 확인할 수 있다. 이 조회는 AI를 호출하거나 키·사진을 반환하지 않는다.

이번 로컬 배포 준비에서는 화면·앱 Swift 파일 47개의 해시가 시작 시점과 동일하다. 공개 저장소와 개인 서명용 기준 프로젝트의 Swift 앱·시험 소스 21개도 일치한다. 현재 앱 소스는 앞선 실기기 응답 호환 시험에 설치한 소스와 같다. 새 화면이나 필수 단계를 추가하지 않았다.

## 실행

웹은 저장소 루트에서 `npm install` 후 `npm run dev -- --port 4180 --host 127.0.0.1`로 실행한다. 이 개발 서버는 웹 화면과 `api/vision.ts`를 함께 실행한다. 단순 정적 미리보기는 AI 서버를 실행하지 않는다.

로컬 분석 키는 `.env.local`의 `VISION_API_KEY`에 둔다. `VISION_PROVIDER=gemini`이며 `VISION_MODEL`은 선택 사항이다. 기존 프로젝트의 로컬 분석 설정만 재사용했으며 `.env.local`은 Git에서 제외된다. API 키를 브라우저나 앱에 넣지 않는다.

iPhone 프로젝트는 `ios/ParkingGuide/ParkingGuide.xcodeproj`이다. 서명 없는 빌드는 `ios/README.md`의 명령으로 실행한다. 공개 소스에는 개인 서명 설정이 없다. 이미 설치된 앱은 기존 HTTPS 서버 설정을 계속 사용하며, 로컬 웹을 켰다는 이유로 iPhone의 접속 서버가 자동으로 바뀌지는 않는다.

로컬 진단은 앞선 iPhone 시험과 같은 합성 사진에서 만든 분석용 JPEG를 Mac에서 전송했다. AI가 작은 빨간 시설을 소화전이라고 답했지만, 이는 AI의 관찰 주장이다. 실제 거리·법적 적용은 `unverified`이고 유형 판정은 추가 맥락이 필요한 상태다. 실제 사진 정확도나 위반 판단 통과로 해석하지 않는다. 기기의 원본 PNG 바이트는 유지했으며, Mac 진단용 JPEG 인코딩과 iPhone의 JPEG 인코딩은 서로 다를 수 있다.

첫 응답이 지정한 소화전 영역을 기존 원본에서 잘라 전체 사진과 함께 재전송했다. 두 번째 응답은 몸체·상단 캡을 상세 설명했지만 차량 관계는 확정 근거로 승격하지 않았고 `ruleTypes`는 빈 배열, 상태는 `needs_context`로 남았다. 이 시험은 Mac의 API 경로를 검증한 것이며 앱의 자동 부분 확대·병합을 실제 기기에서 실행한 시험은 아니다.

이번 로컬 진단은 실제 iPhone의 카메라·앨범·화면 조작 시험을 대체하지 않는다. 기존 실기기 호환 시험과 새 로컬 상세 분석 결과를 구분해 기록한다.

## GitHub와 운영 서버

개발 기준 브랜치는 `codex/preserve-evidence-precheck`이다. 변경 코드와 이 기록을 함께 푸시한다. `main`에는 해결되지 않은 충돌 표시가 있어 이번에 병합하거나 강제 덮어쓰기하지 않는다.

앞서 운영 화면 보존용으로 준비한 `codex/vision-api-production-20261015`의 Vercel Preview 빌드는 성공했지만, 사용자 결정에 따라 Production으로 승격하지 않았다. GitHub 연동으로 Preview가 자동 생성되더라도 운영 전환 완료를 뜻하지 않는다. 현재 공개 운영 API의 구형 응답 한계는 남아 있다.

공개 기록에는 실제 사용자 사진, API 키, 기기·개인 서명 식별자를 포함하지 않는다. 상세 진단 JSON과 빌드 로그는 로컬 작업공간의 `outputs/local_app_release_20261015/`에 보관한다.
